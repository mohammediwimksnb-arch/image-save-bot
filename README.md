# بوت حفظ الصور - Discord.js v14

## المتطلبات
- Node.js إصدار 18 أو أحدث.
- تطبيق بوت من Discord Developer Portal.
- تفعيل البوت وإضافته إلى سيرفرك مع صلاحيات:
  - View Channels
  - Send Messages
  - Embed Links
  - Use Application Commands

## التشغيل
1. فك ضغط المشروع.
2. افتح مجلد المشروع في Terminal.
3. نفّذ:
   ```bash
   npm install
   ```
4. انسخ `.env.example` وسمّ النسخة `.env`.
5. ضع القيم الصحيحة:
   - `DISCORD_TOKEN`: توكن البوت من صفحة Bot.
   - `CLIENT_ID`: Application ID من صفحة General Information.
   - `GUILD_ID`: آيدي السيرفر.
6. سجّل أمر السلاش:
   ```bash
   npm run deploy
   ```
7. شغّل البوت:
   ```bash
   npm start
   ```

## استخدام الأمر
داخل السيرفر اكتب `/setup` ثم أدخل:
- `room`: الروم الذي تريد النشر فيه.
- `image1`: رابط الصورة الأولى.
- `image2`: رابط الصورة الثانية.
- `image3`: رابط الصورة الثالثة.

ينشر البوت الصورتين الأولى والثانية في رسالة واحدة، والثالثة في رسالة ثانية مع زر **حفظ الصور**. عند ضغط الزر يرسل البوت الصور الثلاث إلى الخاص.

## ملاحظات
- الأمر متاح لمن لديه صلاحية Manage Server (ManageGuild).
- استخدم روابط HTTPS مباشرة للصورة، مثل روابط ملفات JPG أو PNG أو WEBP. روابط صفحات مواقع الصور قد لا تعمل كصور مضمنة.
- يجب أن يسمح العضو باستقبال الرسائل الخاصة من أعضاء السيرفر حتى تصله الصور.
- لا تشارك `DISCORD_TOKEN` مع أي شخص، ولا ترفعه إلى GitHub.
- ملف `saved-posts.json` ينشأ تلقائياً بعد أول عملية نشر، ويحتوي روابط الصور اللازمة لعمل الأزرار بعد إعادة تشغيل البوت.
